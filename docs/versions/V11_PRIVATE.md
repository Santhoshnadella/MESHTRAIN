# VERSION 11 — PRIVATE / ENTERPRISE MESH

Goal:

Allow universities, companies and research labs to deploy
their own private MeshTrain networks.

Support:

    private DHT
    private bootstrap
    organization identity
    allowlists
    denylists
    private model registry
    private storage
    private schedulers
    VPN-compatible networking
    policy engine

Example:

    UNIVERSITY MESH

    Lab A
       │
    Lab B ─── Lab C
       │
    GPU Cluster

No public Internet peers required.
