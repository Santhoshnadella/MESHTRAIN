# VERSION 10 — ZERO-TRUST PUBLIC MESH

Goal:

Allow completely unknown Internet participants.

Implement:

    cryptographic identities
    authenticated sessions
    encrypted transport
    capability authorization
    sandboxed workloads
    resource limits
    network isolation
    dataset access policies
    secret isolation
    signed manifests
    signed jobs
    signed checkpoints
    malicious-peer isolation

Security principles:

    NEVER trust peer input
    NEVER execute arbitrary peer code directly
    NEVER expose private datasets unnecessarily
    NEVER expose credentials to workers
    NEVER assume a peer is honest

Acceptance:

    Public participation is possible without giving peers
    unrestricted access to the user's machine or data.
